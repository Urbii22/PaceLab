# Changelog

## 0.1.0 - Fundación

- Proyecto Android privado inicial con Compose y Room.
- Navegación de resumen, actividades, progreso, detalle, ajustes y diagnósticos.

- Modelo local preparado para métricas y series temporales.
- Cálculos puros de ritmo, velocidad, zonas, parciales, agregaciones y deduplicación.
- Tests unitarios y workflow de GitHub Actions para debug, tests y lint.
